<h2 align="center" style="margin-top: 1.5rem;">Distributed Unified Data Engine</h2>

<p align="center" style="font-size: 1.1rem; max-width: 720px; margin: 1.5rem auto; color: #555;">
  Ontul unifies batch processing, stream processing, and interactive SQL queries in a single engine — replacing the sprawl of separate specialized clusters with one system.
</p>

<p align="center" style="font-size: 1.05rem; max-width: 720px; margin: 1rem auto; color: #555;">
  On top of the engine, a built-in <b>semantic layer</b> and <b>ontology</b> serve consistent metrics and objects · links · actions to SQL, BI, and AI agents through the same Arrow Flight SQL and MCP interfaces.
</p>
